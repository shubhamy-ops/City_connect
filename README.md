🚀 CityConnect (Infinity Achiever) 🌐 Smart Civic Issue Reporting & Accountability Platform

CityConnect is a full-stack web platform designed to bridge the gap between citizens and local authorities by enabling real-time reporting, tracking, and resolution of civic issues like potholes, garbage, streetlights, water leaks, and more.

It ensures transparency, accountability, and faster issue resolution using a structured digital workflow.

🎯 Problem Statement

Citizens often face:

Lack of a proper system to report civic issues No transparency in issue resolution Delayed or ignored complaints Poor communication between public and authorities 💡 Our Solution

CityConnect provides a centralized civic management system where:

Citizens can report issues with images + location Authorities can track, assign, and resolve issues Real-time status updates improve transparency Duplicate reports are intelligently managed Escalation ensures unresolved issues are not ignored ⚙️ Key Features 👤 Citizen Features Report civic issues (potholes, garbage, etc.) Upload image evidence Auto location tagging (map-based) Track issue status (Reported → In Progress → Resolved) View history of submitted complaints 🏛️ Authority Dashboard View all reported issues Assign issues to departments/workers Update resolution status Prioritize critical issues Track unresolved cases 🤖 Smart System (Optional/AI Features) Auto categorization of issues Duplicate detection Priority scoring based on severity & location Smart filtering dashboard 🧱 Tech Stack Frontend React.js (Vite) Tailwind CSS / CSS Modules Axios (API calls) React Router Backend Node.js Express.js MongoDB (Database) JWT Authentication (if implemented) Tools Git & GitHub Postman (API testing) VS Code 🏗️ Project Architecture frontend/ src/ components/ pages/ services/ context/
